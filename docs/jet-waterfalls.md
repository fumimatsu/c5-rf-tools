# Jetウォーターフォール: Tab5 0.6.1 / Pyramid 0.2.3

2026-11-15。Tab5は書き込み済み。Pyramidはユーザーが現在接続していないため、ソース更新のみ。Pyramid実機は0.2.2のまま。

## 色と値

両方とも青→水色→緑→黄→赤。受信値は−10〜+45 receiver dB、背景差は0〜+30 dBで固定する。範囲外は端の色へクリップし、凡例に上限・下限を表示する。Pyramidの背景差の従来の色範囲0〜+35 dBをTab5の0〜+30 dBへ統一した。表示範囲の変更であり、保存値・背景計算・判定しきい値は変更しない。

赤は受信値が高いという意味で、異常・混信・故障を示さない。弱い信号や他機との分離の評価は従来の測定境界のまま。受信dBをdBm、SNR、映像品質へ読み替えない。

欠測/無効点は灰色の斜線にし、青の低い有効値と区別する。Pyramidでは背景の点が欠測の場合も無効とし、JavaScriptの `null` を0へ変換して背景差を表示しない。

## 実装

- Tab5: `apps/tab5/main/heat_palette.h` と `ui.cpp`。起動時に256色のRGB565表を作り、WF描画時は参照する。表は512バイト。32段階の色見本と数値を追加。縦レイアウト内で凡例の場所を確保し、WFの表示高さを300→264pxへ変更した。履歴数は最大24掃引のまま。キャンバス計797,696バイト。受信処理・掃引周期・フィルター・明るさ制御は変更しない。
- Pyramid: `apps/pyramid/ui.js` の `heat()` と欠測パターン、`index.html`/`ui.css` の凡例。受信値と背景差で凡例を切り替える。背景採用時に履歴がリセットされる既存のepoch処理を維持する。
- Pyramidのsystemdテンプレートは新しい配置先 `/opt/c5-monitor/0.2.3` を指す。現在の実機サービス定義には触れていない。

## Tab5実機

チップとシリアルを照合し、更新前のNVSとfactory領域をローカルに読み出した。旧アプリの0.6.0記述子と、直前に書き込んだバイナリの一致を確認。パーティション表は読み出してビルド結果と比較した。

アプリ領域 `0x10000` だけを書き込み、ハッシュ一致、0.6.1起動、起動時の全コア/デコーダー試験成功、720×1280・回転0・明るさ10%を確認。NVSは更新前と24,576バイト全て一致。チャンネル・背景・正常基準を保持し、背景の再記録や採用はしていない。

ユーザーが実画面の青→赤WFと数値付き色見本を確認。最終ログは高速4MHzの広域走査で約960フレーム/秒、観測時の累計136,682受信フレームではCRC/seq欠番/C5 drops/重複/クリップ/ゲイン逸脱が0。再起動後にC5の抜き差しが必要になる既存の不安定さは[0.6.0検証](../apps/tab5/docs/rf4-0.6.0-verification.md)を参照。速度改善・高輝度・VTX応答の再検証は今回の確認に含めない。
