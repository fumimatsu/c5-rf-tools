## 元ディレクトリとの文書・構成差

- PyramidのNOTICE.txtは0.1.0表記だったため、ソースの移植準備版0.2.1に整合。
- Pyramidの固定シリアル/全NIC待受/OS固定保存先を、明示シリアル（引数/環境変数）、既定localhost、相対開発保存先へ変更。LANサービスは明示的な設定ファイルと引数を使う。
- Tab5 build.ps1のユーザー専用IDF/Pythonパスと既定COMポートを除去。ESP-IDF環境または引数を使い、書き込み時はポートを明示。
- Tab5 README/AGENTSが参照していた0.5.0検証書は移管元に存在しなかった。未確認の文書を作り直して実機検証済みとは扱わず、handoffへ境界を記載。
- 旧release/evidence/vendorへの参照は移管前の記録であり、統合リポジトリに実体があると誤解しないよう注記。端末バックアップや旧版バイナリーは元PCに保持。
- 生成フォントCのコメントに含まれた元PCパスを伏せ、フォント再生成スクリプトはNodeから変換器を呼ぶ形へ変更。生成済み字形データとアプリの測定処理は変更しない。
