# 別PCのCodexへの引き継ぎ

## 開始時

1. root/対象アプリのAGENTS.mdとdocs/development.mdを読む。
2. Gitのbranch/HEAD/差分を確認。Pyramidの実行版とcheckoutの版を別々に確認。
3. 接続先はユーザーのローカル設定。C5は各アプリ専用の別個体で、Tab5側・Pyramid側を入れ替えない。
4. まずPCテスト/ビルド。SSH認証・書き込み先が不明なら推測して書かない。
