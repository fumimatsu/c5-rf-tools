# 0.4.0 4枠のチャンネル選択と保存

2026-11-13。対象はTab5 ESP32-P4 rev1.3 / MAC <TAB5_SERIAL>、COMx、C5 <C5_SERIAL> / 公式1.2.5+xiaoc5。Tab5のアプリだけ0x10000へ更新した。

## 操作と確認結果

- 4chカードの見出し、または帯域/WF上部の4つの見出しから選択画面を開く。R/A/B/E/Fを選び、8つのチャンネル名とMHzから選ぶ。4枠を独立に変更する。
- 40項目の周波数表を既存C5MK multipilot/web/c5mk-link.jsと全件照合。38項目が選択可能。E7=5925、E8=5945は現アプリの5645–5917MHzの走査・背景・マーカー範囲外のため無効表示。Lowbandは未追加。これは現アプリの範囲で、C5ハードの絶対限界を主張しない。
- 実機CLIで枠0→R8、枠1→A1、枠2→B8、枠3→F8を順番に変更。毎回、変更対象だけが変わること、全4chのcfg/profile=1・mask=f、UIの名前/MHz一致を確認した。
- E7指定は拒否し、設定を変更しない。R7/F8のような同周波数の別名、同じ周波数の複数枠は許可し、名前を保持する（起動時試験）。
- 一括セットE2/E1/F3/F5とR2/R3/R4/R5を実装し、実機で照合した。Rセットのままハードリセットし、CHANNELS_LOADED R2,R3,R4,R5と周波数を確認した。RAM保持を保存成功と扱っていない。
- Rセットで高速69点・詳細137点の正しい周波数リストと全点有効を確認。その後Eセットと4ch監視へ戻した。再起動後の走査刻みは従来通り高速4MHzが初期値。
- ユーザーが物理画面で、見出しから選択画面が開き、選んだ枠の名前とMHzが変わることを確認した。続けて読み戻した時点の4枠はE2,E1,F3,F5、MHz=[5685, 5705, 5780, 5820]。その時点の背景は保存済み・未採用。CLI試験直後の採用状態とは区別する。
- 観測区間のCRC/gaps/drops/bad=0。panic/assert/faultなし。

## 背景の周波数照合

- チャンネル変更時は4ch履歴、受信値/時刻、ピーク、WF、広域の古い値を消去し、C5の新しいリストを確認する。色は枠に固定。変更前の受信値や背景差を新しい名前で表示しない。
- 背景本体は保持するが未採用へ戻す。V2背景には4枠の周波数・順序を追加し、個体/ファーム/測定設定に加えて照合する。名前が別名でも周波数・順序が同じなら照合可能。背景記録中は変更できない。
- 実機でRセットに対する旧Eセット背景の採用が拒否されること、Eセットに戻すと明示採用できることを確認した。GUIの採用ボタンも一致時だけ有効にする。
- 旧V1背景は、元の固定E2/E1/F3/F5の周波数を与えてRAM内でV2に変換する。保存revision 3、mean[-286,-298,-299,-298] centi-dBを維持。旧チェックサムdb3deff9から、周波数を含むV2のcc484fdeへ変わる。新しい背景を測ったという意味ではない。
- 起動・再起動の両ログでBACKGROUND_UPGRADED v1->v2とrevision 3の読込を確認。今回、元のNVS背景は上書きしていない。新しい全機OFF記録をしたときだけV2で保存する。新規V2背景の記録・再読込は今回の実機試験では未実施。
- V1読込を残す理由は、0.3.xの保存背景を持つ実機を更新できるようにするため。0.3.xからの更新対応終了と対象実機のV2再記録への移行確認後に、V1型・変換・読込・試験をまとめて除去できる。V2保存後に旧0.3.xへ戻すと、その新背景を旧版は読めない。

## 設定保存・実装境界

- チャンネル設定はrf4/channelsへ、magic/version/4つのプリセットID/FNVチェックサムとして保存。各手動変更時だけcommitし、連続受信では書かない。保存に失敗した場合は現在設定を変えない。
- 設定版1のID順はR/A/B/E/F各8ch。将来の並べ替えには保存版・移行の見直しが必要。無効/破損した設定はログに記録して初期Eセットで起動する。背景の自動採用は行わない。
- 登録した名前・MHz、履歴凡例、周波数ガイド、IMD候補、履歴CSV見出しを動的な選択に変更。固定E2/E1向け警告文も一般化した。IMDは計算候補で、実測の発生判定ではない。
- 受信機の測定周波数だけを変更し、VTX本体は設定しない。HDZeroのR1–R8を登録できるが、受信電力だけで方式/送信元/BER/映像品質を識別しない。モード別帯域ガイド、HDZero Lowband、R8中心より高い側を含む全帯域の表示は未実装。
- main/app_api.hにSetChannel/ChannelSetを追加。main/rf_core.hに周波数表・設定検証・背景V1変換とV2照合を追加。main/main.cppに保存/読込・適用・CLI、main/ui.cppに選択画面と動的表示を追加。C5 RF処理、SDK、BSP122ファイル、dependencies.lock、c5_decoder.hは0.3.1と同一。
