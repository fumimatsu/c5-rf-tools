# 0.2.0 実機確認と次の段階

Pyramid-Pro http://<PYRAMID_IP>:8765/ に配備済み。Tab5やC5ファームは変更していない。

- 計測・記録 → 計測履歴を記録開始 → 記録停止でセッション保存。
- 右の保存記録を選択し、選択記録を再生。位置スライダーと再生/一時停止が使える。
- 再生時の4ch・しきい値は記録時の設定。実機の受信・記録とは独立した読み取り操作。
- 記録JSONLから元応答、時刻窓、受信値、設定を取り出せる。
- 1920/2560幅で4列、960幅で2列。実機診断と保存一覧を併記する。

実データで約32秒/1264行、4chの元応答を保存。保存欠落0。別セッション記録中の
履歴読出しでも実機記録は継続。サービス再起動時の232行を保存完了し、設定・背景を保持。
4MHz走査は69点/0.461秒、2MHzは137点/0.918秒。UIの再生、シーク、WF切替を確認。
ローカルとPyramidで各9テスト、JS構文、ブラウザーのエラーログなしを確認した。

これは取得・保存・表示の検証。物理ゲート通過精度、USB抜き差し、電源断、独立ラベル、
別しきい値での検出再計算は未検証。保存した極値はC5内部1kHz全サンプルではない。
背景は保存済みを保持し、再起動後は未採用のまま。実測の再校正はしていない。
